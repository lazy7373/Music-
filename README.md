# Free Music Archive (2025–2026)

A growing catalogue of music released from 2025-01-01 through 2026-12-31 that is legally available for free download and redistribution.

## Scope
All genres are welcome: phonk, pop, hip-hop, rap, EDM, indie, rock, classical, regional music, and more.

## Copyright and licensing
A track being free to stream or having a download button does **not** automatically permit re-uploading it to GitHub. MP3 files may be added only when the artist/rightsholder's licence or explicit permission allows redistribution. Keep the licence and required attribution with each track.

## Repository layout
- `catalog/tracks.json` — structured track metadata.
- `SOURCES.md` — discovery sources and verification rules.
- `music/<genre>/<year>/` — MP3 files only after redistribution permission is verified.

## Discovery sources
- [Free Music Archive](https://freemusicarchive.org/)
- [Internet Archive Audio](https://archive.org/details/audio)
- [Jamendo](https://www.jamendo.com/)
- [Bandcamp](https://bandcamp.com/) — check each artist's permissions.
- [SoundCloud](https://soundcloud.com/) — check each creator's permissions.

This is a growing archive, not a claim to contain every song released in 2025–2026.

## Trending charts
- `charts/trending-2026-11-21.json` — worldwide and India chart snapshot with official-audio search links.
- Commercial chart songs are not copied into this repository unless the rights holder explicitly permits MP3 redistribution. The chart file is a discovery index, not an MP3 mirror.
